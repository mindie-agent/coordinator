# coordinator 0.7.5

[English](coordinator-0.7.5.en.md)

## 任务连续性与 SSH 首次连接修复

- 用户已给出凭据时，优先复用共享 `remote_auth` 完成密码认证、公钥安装和密钥验证，不以缺少预建认证配置阻断任务。
- 可选知识、诊断、组件安装和本地记账失败仅影响对应能力；继续可独立推进且已获授权的原生工作，保留任务身份、资源约束和活动作业。
- 远端主操作成功而本地回执失败时保留成功结果和明确警告；外部写入结果未知时先对账再重试。
- 不新增用户业务服务器、NPU 推理或模型精度实测声明。验证范围为本地合同、跨平台 CI、真实隔离 SSH 服务和发布基准。
