# MindIE Coordinator (`mindie-coordinator`) brand assets

The bracketed three-layer stacked Agent mark (central Agent stack framed by symmetrical scheduling brackets) identifies `mindie-coordinator` within the MindIE Agent brand family.

- `coordinator-logo-source.png`: 1254 × 1254 master transparent PNG.
- `coordinator-logo.png`: 512 × 512 transparent PNG for repository READMEs and avatars.
- `coordinator-icon.png`: 128 × 128 compact transparent PNG for UI icons.
- `PROMPT.md`: generation prompt and visual family reference.

Brand accent: `#7045F5` (aligned to the parent [`mindie-agent`](https://github.com/mindie-agent/mindie-agent/tree/main/assets/brand) tile and alpha mask). The same high-contrast mark works on light and dark backgrounds. Preserve its aspect ratio and transparent outer margin.
